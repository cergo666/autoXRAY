## [Unreleased]

## [3.4.0] — 2026-10-16

### Added
- `autoxray warp scan [--apply] [--full] [--colo ..] [--exclude-colo ..]`: параллельная проверка адресов WARP из всех диапазонов Cloudflare, замер задержки внутри туннеля, узел и страна выхода, выбор самого быстрого. Пункт в меню WARP. Идея и диапазоны из warpscout (MIT).
- Очистка и ограничение логов Xray: без лимитов IP журналы очищаются, иначе обнуляются при размере больше 20 МБ. Проверка в `autoxray doctor`.
- В README раздел о том, какие данные хранятся на сервере.

### Changed
- `autoxray warp on` выбирает самый быстрый рабочий endpoint, а не первый рабочий.
- В `autoxray warp status` показываются узел и задержка выбранного endpoint.


## [3.3.0] — 2026-10-16

### Added
- Режим российских сайтов у каждого пользователя: `autoxray user set имя --ru direct|server` (и `--ru` при `user add`). Один клиент может открывать их напрямую с устройства, другой отправлять через сервер и WARP.
- Лимит устройств: `autoxray user set имя --ips N`, команды `autoxray ips` и `autoxray unban`. Лишние IP блокируются правилом Xray на 30 минут, лог доступа включается только при заданных лимитах и очищается раз в минуту.
- В списке версий ядра показываются пререлизы с пометкой и отдельным предупреждением.
- В `autoxray user list` колонки RU и IP, в `autoxray warp status` подробное объяснение маршрутизации и режимы пользователей.
- Расписание обновляется командой `autoxray setup-cron` (вызывается установщиком и `self-update`).

### Changed
- `autoxray warp ru on` больше не меняет подписки: он только отправляет через WARP российские сайты, дошедшие до сервера. Режим клиента задаётся для каждого пользователя отдельно. Существующим пользователям при обновлении сохраняется их прежнее поведение.
- Установщик подробнее объясняет, как работает WARP.
- В названии XHTTP-ссылки убрана приписка «для моста».


## [3.2.0] — 2026-10-16

### Added
- Строка о новой версии autoxray в шапке меню и в `autoxray status` (кэш обновляется раз в 12 часов из cron, меню не ждёт сеть).
- `autoxray core list` и `autoxray core update`: текущая версия Xray, версии новее неё, предупреждение «не обновлять без необходимости», подтверждение и автоматический откат, если конфиг не проходит проверку на новой версии.
- Выбор стрелками, цифрой или клавишами j и k во всех меню; у пользователя своё меню действий (ссылки, QR, лимит и срок, отключение, новые ключи, удаление).
- `autoxray warp debug` (отчёт без секретов и проверка нескольких endpoint'ов) и `autoxray warp endpoint`.

### Changed
- WARP перед включением проверяется отдельным тестовым Xray, перебираются адреса и порты Cloudflare; если ни один не отвечает, WARP не включается (`--force` отключает проверку). Раньше нерабочий WARP с режимом «RU через WARP» мог оборвать доступ к российским сайтам.
- Endpoint WARP по умолчанию задан IP-адресом, а не именем.
- README переписан.

## [3.1.0] — 2026-10-16

### Added
- `autoxray doctor` — диагностика: службы, порты, конфиги, DNS, сертификат и автообновление, BBR, время, диск, гео-данные, файрвол, WARP.
- `autoxray geo-update` и еженедельное автообновление гео-данных (перезапуск Xray только при изменении файлов).
- `autoxray firewall` — ufw с автоопределением порта SSH, подтверждением и режимом `--dry-run`.
- `autoxray user list --plain` для скриптов.

### Changed
- Интерфейс CLI переработан: цветные разделы, эмодзи, галочки вместо `true/false`, полосы расхода трафика с цветом по заполнению, дни до окончания срока, вертикальные подменю WARP и обновлений.
- Выравнивание таблиц не зависит от локали сервера (раньше кириллица сдвигала колонки).
- Итоговый экран установщика оформлен и сгруппирован.

### Fixed
- Установщик печатал `\033[1;36m` вместо цветов в итоговом выводе.
- Личная страница подписки не помещалась по ширине при раскрытии списка конфигов.

## [3.0.0] — 2026-10-16

Полная переработка. Один установщик, один CLI, одно состояние.

### Added
- `autoxray` — CLI и текстовое меню: пользователи, лимиты трафика и сроки, ежемесячный сброс, статистика, бэкап и восстановление, обновление (`self-update`), удаление.
- Несколько пользователей: у каждого свои UUID, пароль Hysteria2 и личная страница подписки; отзыв доступа не затрагивает остальных.
- Учёт трафика по пользователям (статистика Xray) и заголовок `subscription-userinfo` в подписках.
- Cloudflare WARP как встроенный `wireguard`-outbound Xray: свой список доменов и режим «российские сайты через WARP».
- Режим моста RU → EU в том же установщике (`install.sh домен vless://...`), узлы управляются через `autoxray node`.
- Новая адаптивная страница подписки (светлая/тёмная тема, QR, кнопки Happ и v2rayTun, остаток трафика).
- Перенос установки autoXRAY 2 (`autoxray migrate`, запускается установщиком автоматически): UUID, ключи и ссылка подписки сохраняются.
- Docker-тесты (`tests/run.sh`): настоящие Xray и nginx, трафик через все протоколы, мост из двух контейнеров, установщик и миграция.
- Система релизов: `VERSION`, CHANGELOG, CI, автоматическая публикация релиза по тегу.

### Changed
- Конфиги Xray, nginx и подписок собираются из `/etc/autoxray/state.json` (`autoxray render`); правка `config.json` вручную больше не сохраняется.
- Закрытый ключ TLS доступен только root и группе, под которой работает xray (раньше `644` для всех).
- Новый конфиг Xray проверяется `xray run -test` перед применением, при ошибке остаётся прежний.
- Установщик останавливается на ошибках (apt, Xray, сертификат, `nginx -t`), проверка DNS учитывает несколько A-записей и внешний адрес.
- Путь формы входа на сайте-маскировке выбирается случайно.

### Removed
- Устаревшие скрипты (`old/`), тестовые копии (`test/`), отдельный `bridgeTLSxhttp.sh`, `warp-cli`-схема.
